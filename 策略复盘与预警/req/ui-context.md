# UI Context · 策略复盘与预警（样式风格中间产物）

Source: 模型原生 + taste 品味基线（视觉方向由**现有系统截图 `页面1~4.png` 明确锁定**——taste.md：「需求已钉死视觉方向时照其执行」；工作空间无业务前端样式代码，来源 B 存量挖掘不适用；`public-template/` 无沉淀模板，来源 C 静默跳过）。**第七轮 `UI1.png` 增补**：模块一漏斗青→蓝渐变 + 顶部浅灰工具条，实测像素规格见下。**第八轮**：模块一全量对齐 UI1.png 复核；预警策略表新增「策略分类」列（文本列，沿用紧凑表头）；逐策略表前三列表头改横向（去处竖向堆叠）。

Design Read：把此需求读作**运营商策略运营的「复盘与预警」数据工作台**，给策略运营/分析人员用，高密度数据、冷静克制、蓝主色 + 涨绿跌红、数字等宽对齐、卡片网格承载。

## 产品类型与用户

- 产品类型：企业级数据看板 / 运营分析工作台（Data-Dense Dashboard）。
- 用户：策略运营、策略分析人员（单角色）。
- 使用语境：桌面端大屏为主，长时段高频查数、比对环比、下钻单一指标与单条策略。

## 字体

- 标题/正文：系统中文字体栈 `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", sans-serif`（中文场景零摩擦，避免外部 webfont）。
- 数字列：`font-variant-numeric: tabular-nums`（等宽对齐，便于纵向比数）。
- 字阶：区块标题 15px/600 ｜ 卡片数值 22px/700 ｜ 表头 12px/600 ｜ 单元格 13px ｜ 辅助说明 12px。
- 采用理由：参考系统为中文后台、未使用特殊西文字；原型须 file:// 离线双击即开，不引外部字体。

## 密度与间距

- 基础栅格 4px；区块内边距 16px；区块间距 16px；卡片内边距 12px。
- 表格：表头高 36px、行高 36px、单元格左右内边距 12px；表格默认 `border-collapse: collapse`。
- 圆角：卡片 6px ｜ 按钮/输入 4px ｜ 徽标 4px。边框 1px `--border`；卡片阴影极轻 `0 1px 2px rgba(0,0,0,.03)`（不用重投影）。

## 组件风格

- **卡片**：白底 + 1px 描边 + 6px 圆角；标题带左侧 3px 蓝色竖条（`▎` 视觉，截图同款）。
- **KPI 卡**：标签 + 大数值 + 单位 + 环比/同比两行（含色）、右上角线性图标（内联 Lucide，禁 emoji）。
- **按钮**：主＝品牌蓝底白字；次＝白底描边；文字链接＝品牌蓝。
- **下拉/输入**：白底、1px 描边、4px 圆角、聚焦环 `--brand` 2px。
- **表格**：表头浅灰底 `#FAFBFC` + `--muted` 文字；行 hover 浅蓝底；数字列右对齐、等宽。
- **徽标**：如「已过期」灰底灰字、触点标签淡蓝描边。
- **图表**：柱＝品牌蓝；环比折线＝琥珀 `--accent`（点带白描边）；环形图＝10 色分类板；无渐变、无 3D。
- **全屏遮罩**：半透明黑 `rgba(0,0,0,.45)` + 白色面板铺满内容区。

## UX / 无障碍 / 响应式规则

- 焦点环可见（`outline: 2px solid var(--brand); outline-offset: 1px`），键盘 Tab 顺序与视觉顺序一致。
- 宽表用 `overflow-x: auto` 包裹，窄屏不崩。
- 三态齐备：loading（加载中）/ empty（说清为何空 + 去哪做第一件事）/ error（说清出了什么 + 重试入口）。
- 对比度 AA：主文字/按钮文字对底 ≥ 4.5:1；涨跌色同时辅以 `+`/`-` 符号（不单靠颜色传达）。
- `prefers-reduced-motion: reduce` 时关闭过渡动画；交互过渡 150–200ms。
- 响应式断点：≥1440 三栏并行 ｜ 1024–1440 两栏 ｜ <768 单栏 + 表格横向滚动。

## 反模式（禁）

- 禁 AI 紫/紫粉渐变/霓虹外发光作主色或按钮光晕（taste 禁令 2）。
- 禁 emoji 当功能图标（统一内联 Lucide SVG sprite）。
- 禁无可见 `<label>` 的输入框（placeholder 只作示例值）。
- 禁「John Doe / Lorem ipsum」类假名假数；一律用贴合运营商业务的中文策略名与带毛边的数值。
- 禁为「看起来像设计过」而加装饰性编号/分隔线；密度与层级本身就是设计。
- 不引入渐变、重投影、3D、超大圆角等与现有系统不符的「现代化」改造。

## Adoption Notes

（生成代码后必填；C5 校验非空。）

- Applied: 引擎与截图交叉确认的多项已全部落地。
  - 引擎 `--design-system "telecom enterprise analytics dashboard"` → **Data-Dense Dashboard** 风格（最小内边距 / KPI 卡 / 网格 / 最大数据可见性）；配色 Primary/Secondary 蓝 + CTA 琥珀与截图一致 → 采纳，取样微调为 `--brand #2563EB` / `--chart-bar #3B82F6` / `--chart-line #0EA5E9` / `--accent #E6A23C`。
  - 引擎 `--domain chart`（Funnel/Trend/Bar/Pie）→ 采纳「趋势用柱+线、分类对比用柱、占比用环形图、带数值标签」；模块一按 `表格1.png` 绘制**灰色 4 级漏斗**（推送量→使用量→触达量→转化量，段内仅标签无数值），模块四绘制策略拒绝原因环形图。
  - `表格1.png` 精确复刻：模块一左栏指标块为**蓝底白字**（`--brand` 底 + 白字，`名称 + 数值` 与 `环比` 同列单行），左右两列为大号、中部列为紧凑型；`环比` 在蓝底上**保持白色单色**以贴合原图（不套用绿/红涨跌色）；中部指标块 → 漏斗之间保留灰色指向箭头。
  - 引擎 `--domain ux`：Focus States（High）/ Keyboard Navigation（High）/ Table Handling→横向滚动（Medium）/ Bulk Actions（复选框列）→ **全部采纳**（预警策略表「已选 0 项」复选框列与截图一致）。
  - **第七轮 `UI1.png` 特化**：漏斗配色改为**青→蓝渐变**（`--funnel-1~4` 实测值，替代灰色阶）；模块一顶部改**浅灰工具条** `--toolbar #F5F7FA` 承载筛选控件并细分隔（`R36/R37`）；指标快照维持第五轮浅色版式，右栏柱线组合保留（`USR-20`）。
  - **第八轮**（`R38~R40`）：模块一按 UI1.png 全量复核（`R38`）；预警策略表新增「策略分类」列——文本列、沿用 `[data-section="stockFocus"]` 紧凑表头（padding 5×8、`white-space:nowrap`），数据为规则名称（`R39`）；逐策略表前三列表头去竖向堆叠改**横向单行**，行高与其他列一致（`R40`）。
  - **第九轮**（`R43~R45`）：逐策略表去留白、每页扩充（size 5→12，行高 padding 5→4px 微压缩，`R43`）；策略详情移除「展开/收起」按钮与折叠逻辑、字段全部常显（改 `.detail-list` 为常显、删除 `.detail-list--collapsible`/`.is-collapsed`，`R44`）；模块一工具条新增「重点客群」按钮（离后）+「重点客群」下拉（触点切换左侧、默认 hidden、点按钮切换显隐，`R45`）。
  - **第十轮**（`R47~R50`）：「重点客群」按钮与分类按钮组互斥（`applySegMutex` 统一维护 `aria-pressed`，任一时刻至多一个选中）；选分类→下拉强制隐藏、选重点客群→下拉显示（`R47/R48`）；三节点校验 `validateSegState`（初始化/点击/组件更新）自动回滚 + `window.__SEG_STATE__` 快照（`R49`）。
- Deferred: 引擎的部分通用建议与现有系统/离线约束冲突，暂不采纳并说明理由。
  - 引擎 typography 推荐 `Fira Code / Fira Sans` webfont → **不采用为默认**：参考系统是中文后台、使用系统字体，且原型要求 file:// 离线双击即开、不引外部字体；改用系统中文字体栈 + `tabular-nums`。若上线正式设计系统另有字体规范，再行替换。
  - 引擎 Pattern `Enterprise Gateway`（hero / logo carousel / contact sales / mega menu）→ **不适用**于内部数据工作台，延后不采纳。
- Not adopted: 以下方向与现有系统设计语言不符，未采纳。
  - 营销页/落地页结构与动效（marquee、bento、hero 序列等）——本分身产功能型数据原型，不适用。
  - 深色 OLED / 玻璃拟态 / 新拟态 / 粗野等风格——与现有系统设计语言不符，未采纳。
