# Delta Spec: 预警规则功能修复

## 修改需求：rule-dialog

### 场景：收藏功能

**Given** 用户点击收藏按钮
**When** 提交收藏请求
**Then** 接口返回成功（HTTP 200）
**And** 不提示"不能为空"

### 场景：新增规则

**Given** 用户填写完规则表单并提交
**When** 调用 ruleCreate 接口
**Then** 接口返回成功（HTTP 200）
**And** 规则创建成功

### 场景：规则配置按用户编码过滤

**Given** 用户在规则配置查询页面输入用户编码
**When** 点击搜索
**Then** 列表只显示该用户编码的规则
**And** 支持清空用户编码查看全部
