# 设计文档

## 1. 被动/控损策略详情无数据

### 现状
- `ExecutionDetail.vue` 的 `fetchStrategyInfo` 方法在 tab_type 切换时未正确传递参数
- 后端 `StrategyReviewServiceImpl` 的策略详情查询可能未适配 passive/control 表

### 方案
- 前端：确保 `fetchStrategyInfo` 在 tab_type 变化时重新调用，并正确传递 `tabType` 参数
- 后端：检查 `selectStrategyInfo` SQL 是否适配三张表（ap/passive/control）

## 2. 表头对齐问题

### 现状
- 表格列宽使用 `min-width`，浏览器缩放时自适应导致表头换行
- 排序按钮占用额外空间

### 方案
- 固定关键列的 `width`（而非 `min-width`）
- 调整表头单元格样式，确保排序按钮不换行

## 3. 收藏功能 bug

### 现状
- `handleAddFavorite` 方法可能缺少必填参数
- 后端收藏接口参数校验可能过严

### 方案
- 检查前端提交的参数结构，确保包含所有必填字段
- 检查后端 `FavoriteController` 的校验逻辑

## 4. 数据不同步

### 现状
- 前端可能硬编码了日期范围（如 `2026-09-01` 到 `2026-09-10`）
- 后端查询条件可能限制了日期范围

### 方案
- 前端：日期范围改为动态计算（如最近 30 天）或扩大范围
- 后端：检查 SQL 的日期过滤条件

## 5. 策略联动失效

### 现状
- tab_type 切换时，策略详情组件未重新加载
- 可能存在缓存导致数据不更新

### 方案
- 使用 `watch` 监听 tab_type 变化，触发重新加载
- 清除相关缓存或强制刷新

## 6. 新增规则无效

### 现状
- `RuleCreateDialog.vue` 的表单提交可能缺少必填字段
- 后端 `ruleCreate` 接口可能参数校验失败

### 方案
- 检查前端表单的 `form` 数据结构，确保包含所有必填字段
- 检查后端接口的 `@RequestBody` 接收逻辑

## 7. 策略小类可读性差

### 现状
- 策略小类字段 CSS 颜色值过浅（如 `#999` 或 `#ccc`）

### 方案
- 调整颜色值为 `#666` 或更深，提高对比度

## 8. 规则配置按用户编码过滤

### 现状
- 规则配置查询页面缺少用户编码筛选条件

### 方案
- 前端：新增用户编码输入框
- 后端：接口支持 `userCode` 参数，SQL 增加过滤条件

## 9. 表格错列

### 现状
- tab_type 切换时，执行明细表格的列定义未正确更新
- 不同 tab_type 的数据字段结构不同

### 方案
- 使用 `v-if` 或 `key` 强制表格在 tab_type 变化时重新渲染
- 确保列定义与数据字段匹配
