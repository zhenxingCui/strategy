# Spec: 策略执行详情

## 需求：daily-detail

### 场景：被动/控损策略详情加载

**Given** 用户切换到被动策略或控损策略
**When** 策略执行详情区域加载
**Then** 策略名称、策略拒绝原因等信息正常显示
**And** 不显示"暂无数据"

### 场景：策略联动

**Given** 用户切换 tab_type（主动/被动/控损）
**When** tab_type 变化
**Then** 策略详情区域重新加载对应 tab_type 的数据
**And** 策略信息随 tab_type 切换而更新

### 场景：执行明细表格不错列

**Given** 用户切换 tab_type
**When** 执行明细表格重新渲染
**Then** 表格列定义与数据字段匹配
**And** 表格不错列

### 场景：主表千分位

**Given** 主表单元格数值为 294000
**When** 渲染单元格
**Then** 显示为 294,000

### 场景：分日表千分位

**Given** 分日表单元格数值为 876000
**When** 渲染单元格
**Then** 显示为 876,000

## 需求：category-summary

### 场景：分类汇总可查

**Given** 库内分类汇总行 strategy_id 为 'ALLSUM'
**When** 查询策略分类执行情况
**Then** 返回分类汇总数据（不写死数字 ID 999）

## 需求：original-cust-removed

### 场景：原始客群列不展示

**Given** 用户查看任意执行/预警相关表格或导出文件
**When** 表格渲染或导出
**Then** 不出现原始客群列（业务侧已确认下线该口径）
